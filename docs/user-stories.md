# User Stories

## User Story 1: Submit IT Support Request

**As an** employee,

**I want to** submit an IT support request,

**So that** the IT Support Team can investigate and resolve my problem.

## User Story 2: Track Support Request

**As an** employee,

**I want to** track the status of my support request,

**So that** I know whether my problem is being worked on or has been resolved.

## User Story 3: Manage Support Ticket

**As an** IT Support Officer,

**I want to** view and manage assigned support tickets,

**So that** I can resolve employee IT problems efficiently.

## User Story 4: Prioritize Critical Issues

**As an** IT Support Officer,

**I want to** assign priority levels to support tickets,

**So that** critical IT problems can be handled quickly.
